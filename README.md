# 中文文本意图分类实验结果分析

## 1. 项目概述

本项目基于 SMP2017 中文人机对话评测数据，构建一个面向用户请求自动分类与业务路由的
**文本意图识**别系统。项目在统一的数据划分和评估标准下，对以下三类模型进行比较：

1. 字符级 TF-IDF + Logistic Regression；
2. Embedding + Pooling + MLP；
3. 预训练中文 BERT 微调。

实验目标不仅是获得较高的分类指标，也包括比较传统机器学习、从零训练的轻量神经网络和预训练语言模型在小规模、多类别中文短文本分类任务中的能力差异。

## 2. 数据集与预处理

### 2.1 数据来源

实验采用 SMP2017-ECDT Task 1 数据。原始数据按类别分别存储为 TXT 文件，每一行对应一条用户表达，文件名中的 `app`、`weather`、`telephone` 等字段表示类别标签。

项目将原始 TXT 文件转换为统一的 CSV 格式：

```text
ticket_id,text,label,split
```

转换过程中保留官方数据划分，没有重新进行随机切分，从而避免测试数据参与训练或参数选择。

### 2.2 数据规模

| 数据集 | 样本数 | 用途 |
| --- | ---: | --- |
| Train | 2,299 | 模型训练 |
| Validation | 770 | 超参数选择与最佳模型选择 |
| Test | 667 | 最终泛化性能评估 |
| 合计 | 3,736 | — |

数据集包含 31 个意图类别。**类别分布不均衡**，例如训练集中 `chat` 有 455 条、`cookbook` 有 269 条，而部分小类别只有约 20～30 条。因此，本项目除 Accuracy 外，重点使用 **Macro-F1** 衡量模型对各类别的整体识别能力。

### 2.3 标签处理

MLP 和 BERT 使用训练集标签动态构建 `label_to_id`：

```python
labels = sorted(trainframe["label"].unique())
label_to_id = {label: index for index, label in enumerate(labels)}
```

同时检查验证集和测试集是否包含训练阶段未见的标签，使代码能够由原来的五分类配置扩展到当前的 31 分类任务。

## 3. 评估指标

三个模型统一使用以下指标：

- Accuracy：全部测试样本中的预测正确比例；
- Macro-Precision：各类别 Precision 的算术平均；
- Macro-Recall：各类别 Recall 的算术平均；
- Macro-F1：各类别 F1 的算术平均；
- Per-class Precision、Recall、F1：分析具体类别表现；
- Confusion Matrix：观察类别之间的主要混淆关系。

由于类别分布不均衡，本文以 Macro-F1 作为主要模型比较指标。

## 4. 整体实验结果

| 模型 | Test Accuracy | Macro-Precision | Macro-Recall | Test Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| TF-IDF + Logistic Regression | 92.50% | 93.69% | 93.38% | 93.20% |
| Embedding + Pooling + MLP | 85.91% | 86.76% | 86.84% | 86.23% |
| BERT | **95.20%** | **96.46%** | **95.76%** | **96.03%** |

整体排名为：

```text
BERT > TF-IDF + Logistic Regression > Embedding + Pooling + MLP
```

BERT 的 Macro-F1 相比 MLP 提升 9.80 个百分点，相比 TF-IDF baseline 提升 2.83 个百分点。按测试集 Accuracy 计算，baseline 错误 50 条，BERT 错误 32 条，说明 BERT 在保持多数易分类类别性能的同时，**进一步减少了语义相近类别之间的误判**。

## 5. 各模型结果分析

### 5.1 TF-IDF + Logistic Regression

Baseline 使用字符级 1～2 gram TF-IDF 特征和 Logistic Regression，搜索得到的最佳配置为：

```text
C = 10
class_weight = balanced
solver = lbfgs
```

验证集 Macro-F1 为 91.11%，测试集 Macro-F1 为 93.20%。该结果说明字符级 TF-IDF 非常适合当前数据集。许多意图类别具有明显的领域词汇，例如：

- `weather`：天气、气温、下雨；
- `flight`：航班、飞机、机场；
- `train`：火车、车次、车票；
- `telephone`：拨打、呼叫、打电话；
- `translation`：翻译、英文怎么说。

传统模型能够直接利用这些**高区分度字符片段**，
因此即使不具备深层语义建模能力，也能取得较强结果。

Baseline 的主要弱项包括：

| 类别 | F1 |
| --- | ---: |
| cinemas | 63.64% |
| music | 80.00% |
| video | 80.70% |
| app | 83.33% |

其中 `video → cinemas` 是最集中的混淆，共出现 5 次。此外，`video` 还会与 `music`、`tvchannel` 和 `epg` 混淆。这说明关键词模型能够识别领域，但难以稳定区分“播放视频”“查询电影”“查询节目单”和“切换电视频道”等相近意图。

### 5.2 Embedding + Pooling + MLP

MLP 的最佳配置为：

```text
vocab_size = 1620
embedding_dim = 128
hidden_dim = 64
dropout = 0.0
learning_rate = 0.001
num_classes = 31
```

测试集 Accuracy 为 85.91%，Macro-F1 为 86.23%，低于 TF-IDF baseline。主要原因是该模型的字符 Embedding 从当前小规模训练集随机初始化，缺少外部语义知识；**Pooling又会弱化字符顺序和局部组合信息**，因此不一定比直接利用 n-gram 的 TF-IDF 更有优势。

训练历史显示出明显的过拟合趋势：

- 最终训练 Accuracy 达到 99.39%；
- 最佳验证 Macro-F1 约为 86.12%；
- 验证损失在第 7 轮左右达到低点，之后逐渐升高；
- 训练损失则持续下降至约 0.05。

这说明后期训练主要在继续拟合训练样本，没有同步提升验证集泛化能力。MLP 的主要弱项为：

| 类别 | F1 |
| --- | ---: |
| cinemas | 45.45% |
| video | 64.86% |
| app | 68.75% |
| music | 69.77% |
| tvchannel | 71.11% |

后续可通过增大 Dropout、加入权重衰减、使用早停、引入 CNN/RNN 局部序列建模，或使用预训练词向量改善结果。但从本次实验看，简单 MLP 并不适合作为该任务的最终模型。

### 5.3 BERT

BERT 使用 `google-bert/bert-base-chinese` 进行微调，最佳配置为：

```text
learning_rate = 3e-5
weight_decay = 0.0
warmup_ratio = 0.1
num_labels = 31
```

BERT 在测试集上取得最高结果：Accuracy 为 95.20%，Macro-F1 为 96.03%。最佳验证 Macro-F1 约为 95.94%，与测试结果非常接近，说明模型在官方划分上的泛化表现较稳定。

BERT 对多个困难类别带来了明显提升：

| 类别    | MLP F1 | Baseline F1 | BERT F1    |
| ---     | ---:   | ---:        | ---:       | 
| cinemas | 45.45% | 63.64%      | **87.50%** |
| music   | 69.77% | 80.00%      | **95.45%** |
| video   | 64.86% | 80.70%      | **86.89%** |
| health  | 80.00% | 88.24%      | **97.30%** |

这些提升说明预训练模型能够利用上下文语义，而不只是依赖某个类别关键词。例如，当一句话同时出现“电影”和“播放”时，BERT 更有可能根据完整表达判断用户是在查询电影院信息，还是请求播放视频。

BERT 在第 7 轮左右达到最佳验证结果，之后指标基本稳定，而训练 Accuracy 已达到 100%。因此继续训练收益有限，后续可以加入 patience 为 2～3 的 Early Stopping，以减少不必要的训练时间并降低过拟合风险。

## 6. 模型对比结论

### 6.1 为什么 TF-IDF 强于 MLP

当前数据以中文短文本为主，不少类别可以通过**少量关键词或字符组合识别**。字符级 TF-IDF 能直接保留这些**局部模式**，而简单的 Embedding + Pooling 会以字符为单位，将文本压缩为单个向量，可能**丢失局部顺序和关键组合信息**。与此同时，MLP 的 Embedding 需要从 2,299 条训练数据中从零学习，数据量不足以形成稳定的语义空间。

### 6.2 为什么 BERT 表现最好

BERT 已在大规模中文语料上**完成预训练**，能够利用词语组合、上下文关系和整句语义。在 `video/cinemas/epg/tvchannel`、`music/poetry` 等边界接近的类别上，这种能力比单纯依赖字符频率更有效。

### 6.3 性能与成本权衡

| 方案 | 优点 | 局限 | 适用场景 |
| --- | --- | --- | --- |
| TF-IDF + LR | 训练快、资源占用低、效果强、容易解释 | 语义理解能力有限 | CPU 部署、低延迟、快速 baseline |
| Embedding + MLP | 结构简单，可作为神经网络入门实验 | 小数据上易过拟合，效果低于 baseline | 教学实验、轻量网络结构验证 |
| BERT | 综合效果最好，擅长语义相近类别 | 训练和推理成本较高 | 对准确率要求较高的在线或离线分类 |

若业务优先考虑性能和部署成本，TF-IDF + Logistic Regression 已具有较高实用价值；若更关注分类效果，尤其是相近意图的区分，应优先选择 BERT。

## 7. Bad Case 分析

本项目保存了测试集错误样本、预测标签和模型置信度，用于分析以下问题：

1. **相近业务边界**：`video`、`cinemas`、`epg` 和 `tvchannel` 都可能包含“电影、电视、节目、播放”等词；
2. **跨领域表达**：同一句话可能同时包含应用名称、内容类型和操作请求；
3. **短文本信息不足**：部分请求只有少量字符，缺少足够上下文；
4. **类别不均衡**：小类别训练样本有限，类别级指标波动更明显；
5. **高频类别吸附**：模型可能倾向于将边界样本预测为训练样本较多的类别。

后续可以针对高频混淆类别补充边界样本，检查标注定义，并使用置信度阈值识别低置信度请求。对于低于阈值的预测，可路由至人工处理或返回候选类别，从而降低自动路由中的高风险误判。

## 8. 实验局限与后续工作

本实验仍存在以下局限：

- SMP2017 属于通用人机对话意图分类数据，不是企业真实工单；
- 部分类别样本较少且分布不均衡；
- 当前评估仅基于单次官方数据划分；
- 尚未系统评估模型推理延迟、吞吐量和模型大小；
- Softmax 最大概率不能直接等同于可靠置信度，实际部署前还需要进行概率校准。

后续计划包括：

1. 引入 Early Stopping，减少 MLP 和 BERT 的过拟合；
2. 对 `video/cinemas/epg/tvchannel` 等类别开展针对性数据增强；
3. 增加 CNN、RNN 或 LSTM，与当前三种模型继续比较；
4. 统计模型参数量、推理耗时和资源占用，形成效果—成本综合评估；
5. 使用温度缩放等方法校准预测概率，并设计低置信度人工兜底策略；
6. 在具备合规数据来源的前提下，引入真实客服或工单数据验证迁移效果。

## 9. 最终结论

实验表明，在 SMP2017 的 31 类中文短文本意图分类任务中，TF-IDF + Logistic Regression 能以较低成本取得 93.20% 的 Macro-F1，是一个强有力的 baseline；从零训练的 Embedding + Pooling + MLP 受数据规模和模型结构限制，Macro-F1 为 86.23%，并出现明显过拟合；预训练 BERT 取得最佳 Macro-F1 96.03%，尤其改善了多个语义边界接近的困难类别。

综合效果与成本，项目验证了传统特征模型在关键词明显的短文本任务中仍具有竞争力，同时也说明预训练语言模型在复杂语义和相近意图区分方面具备更明显的优势。
