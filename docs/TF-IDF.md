1. 什么是TF-INF：
    1. 提取特征：TfidfVectorizer(analyzer="char",ngram_range=(1, 2))
        规定按照字作为划分单位，(1,2)表示提取1个字和2个字长度的文本特征。
        假设训练集只有两条文本：
            文本1：**宽带故障**
            文本2：**宽带断网**
        文本1提取出的特征：
            单字符：宽 带 故 障
            双字符：宽带 带故 故障
        因此文本1共有这些特征：
            宽、带、故、障、宽带、带故、故障
        文本2提取出的特征：
            单字符：宽 带 断 网
            双字符：宽带 带断 断网
        因此文本2共有：
            宽、带、断、网、宽带、带断、断网
        把两条训练文本合在一起，TF-IDF会建立一个总词表：
            宽、带、故、障、断、网、宽带、带故、故障、带断、断网(len=11)
        所以每条文本最终都会变成一个长度为11的向量。
        **至此完成了传统的bulid_char_to_id(遍历每一条文本)**
        **以及规定了max_len(特征总数)**
    
    2. TF：Term Frequency某个特征在当前文本中出现了多少次
        对于文本1：宽带故障
        特征	TF
        宽	    1
        带	    1
        故	    1
        障	    1
        断      0
        网      0
        宽带	1
        带故	1
        故障	1
        带断    0
        断网	0
        但是，只看出现次数TF还不能决定文本的编码。因为有些特征可能在所有文本里都会出现，它们虽然出现很多，却没什么区分能力。
    
    3. IDF：Inverse Document Frequency某个特征在整个训练集中有多稀有
        IDF(t)=ln((1+N)/(1+DF(t))​)+1
        N：训练集文本总数
        DF(t)：包含特征t的文本数量
        **每个特征的IDF是固定的，与它在哪条文本中没关系，因为IDF是全局计算的**

        例：
        这里训练集一共有两条文本，所以N=2
        两条文本都包含“宽带”，所以：DF(宽带)=2
        代入公式：
            IDF(宽带)=ln(1+2/1+2)+1=ln(1)+1=1
        所以：宽带的IDF = 1

        只有文本1包含“故障”，所以：DF(故障)=1
        代入公式：
            IDF(故障)=ln(1+1/1+2)+1=ln(2/3)+1≈1.405
        **越稀有的特征IDF越大**
    
    3. TF-IDF: TF * IDF
        因此，文本1可以暂时表示成：
            宽带  故障   断网
            1   1.405   0
    
    4. L2归一化：
        对每条文本的向量进行L2归一化。它会让每条文本向量的长度变成1：
        如果不归一化，它可能因为字符更多，总分普遍更大。但文本更长不代表它一定更重要，所以需要减少文本长度的影响。

        文本1归一化之前大致是：
        宽       1
        带       1
        宽带     1
        故       1.405
        障       1.405
        断       0
        网       0
        带断     0
        断网     0
        带故     1.405
        故障     1.405

        所以文本1最终大致是：
        特征	最终 TF-IDF
        宽	    0.303
        带	    0.303
        宽带	0.303
        故	    0.426
        障	    0.426
        带故	0.426
        故障	0.426
        断	    0
        网	    0
        带断	0
        断网	0

        文本1：[0.303,0.303,0.426,0.426,0,0,0.303,0.426,0.426,0,0]
        文本2：[0.303,0.303,0,0,0.426,0.426,0.303,0,0,0.426,0.426]

        合起来就是一个矩阵：形状是(2, 11)
        含义：
            2行：两条文本
            11列：11个字符或字符组合特征
        这就是**train_features**
        **至此完成了encode_text工作(长度不是特征数而是规定的max_len，通过padding对齐)**


2. 当使用训练集数据构建词表，对训练集编码后，**应使用相同词表对验证集编码**
    但遇到训练集词表中没有的词时，需要跳过：
    验证文本：宽带断了
    其中：
        “宽”在训练词典中
        “带”在训练词典中
        “断”没在训练词典中
        “了”没在训练词典中
    所以TF-IDF只会处理“宽”和“带”：
        宽    带    故    障    费    用    过    高
        有值  有值   0     0     0     0     0     0
    大致表示为：
        [0.707, 0.707, 0, 0, 0, 0, 0, 0]
    “断”和“了”不会获得新列，而是直接被忽略。
